### 3.1. User Stories
En esta sección se verán las historias de usuario que ayudarán en el desarrollo de la plataforma Vantage, enfocándonos en resolver la fragmentación de la información y mejorar el control estratégico.

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |
| :--- | :--- | :--- | :--- | :--- |
| **EP01 / US01** | Creación de Proyectos Centralizada | **Como** PMO Lead, **quiero** crear nuevos proyectos asignando cliente, fechas y prioridad **para** tener un registro único de todos los avances de trabajo. | **Scenario 1:** Registro de proyecto con éxito<br>**Dado que** el PMO Lead se encuentra en el formulario de "Nuevo Proyecto"<br>**Cuando** ingresa el nombre, cliente y fechas válidas y hace clic en "Guardar"<br>**Entonces** el sistema registra el proyecto y lo muestra en la lista de portafolio.<br><br>**Scenario 2:** Validación de fechas<br>**Dado que** el PMO Lead está creando un proyecto<br>**Cuando** selecciona una fecha de fin anterior a la fecha de inicio<br>**Entonces** el sistema muestra un mensaje de alerta "La fecha de fin debe ser posterior" y bloquea el botón de guardado. | **EP01: Project** |
| **EP02 / US02** | Visualización de Portafolio | **Como** Ingeniero Tecnológico, **quiero** visualizar una lista de todos los proyectos activos con su estado actual **para** identificarlo de manera rápida. | **Scenario 1:** Visualización de lista de proyectos<br>**Dado que** el usuario ingresa a la plataforma<br>**Cuando** navega a la sección "Portafolio"<br>**Entonces** el sistema muestra una tabla con todos los proyectos, indicando su estado con colores (Verde, Amarillo, Rojo). | **EP02: Portafolio** |
| **EP02 / US03** | Estandarización mediante Plantillas | **Como** Líder de gestión, **quiero** utilizar plantillas predefinidas al crear proyectos **para** asegurar que todos los equipos sigan el mismo estándar de documentación. | **Scenario 1:** Aplicación de plantilla<br>**Dado que** el usuario está configurando un nuevo proyecto<br>**Cuando** selecciona la plantilla "Desarrollo de Software"<br>**Entonces** el sistema carga automáticamente las fases, hitos y carpetas de documentos predeterminadas. | **EP02: Portafolio** |
| **EP03 / US04** | Asignación de Tareas con Responsables | **Como** Coordinadora de Operaciones, **quiero** asignar tareas específicas a miembros del equipo con fechas límite **para** que cada persona tenga claridad sobre sus responsabilidades. | **Scenario 1:** Asignación exitosa<br>**Dado que** la Coordinadora crea una nueva tarea<br>**Cuando** selecciona a un miembro del equipo del menú desplegable y asigna una fecha<br>**Entonces** el sistema guarda la tarea y notifica al responsable asignado. | **EP03: Project Manager** |
| **EP11 / US05** | Report | **Como** miembro del equipo, **quiero** adjuntar documentos directamente a una tarea o proyecto **para** evitar que la información se pierda en correos o chats. | **Scenario 1:** Subida de archivo soportado<br>**Dado que** el usuario está en los detalles de una tarea<br>**Cuando** sube un archivo PDF o Excel menor a 10MB<br>**Entonces** el sistema adjunta el archivo y permite su visualización al resto del equipo. | **EP11: Report** |
| **EP09 / US06** | Project Status | **Como** usuario de la plataforma, **quiero** dejar comentarios en las tareas **para** mantener una comunicación fluida sobre los avances sin salir del sistema. | **Scenario 1:** Publicación de comentario<br>**Dado que** el usuario visualiza una tarea activa<br>**Cuando** escribe un mensaje en la caja de comentarios y presiona "Enviar"<br>**Entonces** el comentario aparece inmediatamente con la fecha, hora y nombre del autor. | **EP09: Project Status** |
| **EP08 / US07** | Dashboard | **Como** PMO Lead, **quiero** ver un gráfico de salud del portafolio basado en el cumplimiento de plazos **para** tomar decisiones preventivas sobre proyectos en riesgo. | **Scenario 1:** Actualización de salud en riesgo<br>**Dado que** un proyecto tiene tareas vencidas<br>**Cuando** el PMO Lead ingresa al Dashboard Ejecutivo<br>**Entonces** el sistema muestra el indicador de salud en color "Amarillo" o "Rojo" según la gravedad. | **EP08: Dashboard** |
| **EP11 / US08** | Report | **Como** Gerente, **quiero** generar un reporte consolidado en PDF del estado de los proyectos **para** presentarlo en reuniones sin consolidar datos manualmente. | **Scenario 1:** Generación de reporte exitosa<br>**Dado que** el Gerente visualiza el resumen de un proyecto<br>**Cuando** hace clic en el botón "Exportar PDF"<br>**Entonces** el sistema descarga un documento con el avance actual y el logo de la empresa. | **EP08: Dashboard** |
| **EP10 / US09** | Notificación de Vencimiento de Tarea | **Como** usuario operativo, **quiero** recibir una notificación antes de que venza una tarea asignada **para** priorizar mi jornada y evitar retrasos. | **Scenario 1:** Envío de alerta preventiva<br>**Dado que** una tarea está a 24 horas de su fecha límite<br>**Cuando** el sistema realiza la validación automática<br>**Entonces** envía una alerta visual al centro de notificaciones del usuario responsable. | **EP10: Alert y Report** |
| **EP10 / US10** | Alerta | **Como** PMO Lead, **quiero** recibir una alerta si un proyecto no ha tenido actualizaciones en 3 días **para** intervenir y conocer la causa de la detención. | **Scenario 1:** Detección de inactividad<br>**Dado que** un proyecto activo no registra cambios<br>**Cuando** pasan 72 horas sin actividad en tareas o comentarios<br>**Entonces** el sistema envía un aviso al correo del administrador del proyecto. | **EP10: Alert** |
| **EP01 / US11** | Edición de Proyectos | **Como** Project Manager, **quiero** editar la información de un proyecto existente **para** mantener actualizados los datos del portafolio. | **Scenario 1:** Edición exitosa<br>**Dado que** el Project Manager accede al detalle del proyecto<br>**Cuando** modifica los datos y guarda los cambios<br>**Entonces** el sistema actualiza la información correctamente.<br><br>**Scenario 2:** Datos inválidos<br>**Dado que** el usuario ingresa datos incompletos<br>**Cuando** intenta guardar<br>**Entonces** el sistema muestra un mensaje de error y no permite continuar. | **EP01: Project** |
| **EP01 / US12** | Eliminación de Proyectos | **Como** PMO Lead, **quiero** eliminar proyectos que ya no son necesarios **para** mantener organizado el sistema. | **Scenario 1:** Eliminación exitosa<br>**Dado que** el proyecto existe<br>**Cuando** el usuario selecciona eliminar<br>**Entonces** el sistema elimina el proyecto del portafolio.<br><br>**Scenario 2:** Proyecto inexistente<br>**Dado que** el proyecto no existe<br>**Cuando** se intenta eliminar<br>**Entonces** el sistema muestra un mensaje de error. | **EP01: Project** |
| **EP03 / US13** | Seguimiento de Tareas | **Como** Project Manager, **quiero** visualizar el estado de las tareas **para** monitorear el avance del proyecto. | **Scenario 1:** Visualización correcta<br>**Dado que** existen tareas registradas<br>**Cuando** el usuario accede al módulo de tareas<br>**Entonces** el sistema muestra el estado actualizado de cada tarea. | **EP03: Project Manager** |
| **EP05 / US14** | Asignación de Recursos | **Como** PMO Lead, **quiero** asignar recursos a proyectos **para** optimizar el uso del equipo. | **Scenario 1:** Asignación exitosa<br>**Dado que** el recurso está disponible<br>**Cuando** se asigna a un proyecto<br>**Entonces** el sistema registra la asignación correctamente.<br><br>**Scenario 2:** Recurso no disponible<br>**Dado que** el recurso ya está asignado<br>**Cuando** se intenta asignar nuevamente<br>**Entonces** el sistema muestra una alerta de conflicto. | **EP05: Resource Management** |
| **EP05 / US15** | Visualización de Recursos | **Como** PMO Lead, **quiero** visualizar todos los recursos disponibles **para** tomar decisiones de asignación. | **Scenario 1:** Lista de recursos<br>**Dado que** existen recursos registrados<br>**Cuando** el usuario accede al módulo de recursos<br>**Entonces** el sistema muestra la lista completa de recursos. | **EP05: Resource Management** |
| **EP08 / US16** | Visualización de KPIs | **Como** Stakeholder, **quiero** visualizar indicadores clave del proyecto **para** evaluar su desempeño. | **Scenario 1:** Visualización de KPIs<br>**Dado que** existen datos del proyecto<br>**Cuando** el usuario accede al dashboard<br>**Entonces** el sistema muestra los indicadores actualizados. | **EP08: Dashboard** |
| **EP08 / US17** | Actualización en Tiempo Real | **Como** usuario, **quiero** que la información del dashboard se actualice automáticamente **para** tener datos confiables. | **Scenario 1:** Actualización automática<br>**Dado que** ocurre un cambio en el proyecto<br>**Cuando** el sistema procesa la información<br>**Entonces** el dashboard refleja los cambios en tiempo real. | **EP08: Dashboard** |
| **EP11 / US18** | Generación de Reportes por Proyecto | **Como** Project Manager, **quiero** generar reportes específicos por proyecto **para** analizar su rendimiento. | **Scenario 1:** Generación correcta<br>**Dado que** el proyecto tiene datos registrados<br>**Cuando** el usuario solicita el reporte<br>**Entonces** el sistema genera el reporte con la información correspondiente. | **EP11: Report** |
| **EP10 / US19** | Alerta de Presupuesto | **Como** PMO Lead, **quiero** recibir alertas cuando se excede el presupuesto **para** tomar acciones correctivas. | **Scenario 1:** Detección de sobrecosto<br>**Dado que** el proyecto supera el presupuesto<br>**Cuando** el sistema detecta la desviación<br>**Entonces** envía una alerta al usuario responsable. | **EP10: Alert** |
| **EP07 / US20** | Autenticación de Usuario | **Como** usuario, **quiero** iniciar sesión en la plataforma **para** acceder a mis proyectos. | **Scenario 1:** Inicio de sesión exitoso<br>**Dado que** el usuario tiene credenciales válidas<br>**Cuando** ingresa sus datos correctamente<br>**Entonces** el sistema permite el acceso.<br><br>**Scenario 2:** Credenciales inválidas<br>**Dado que** el usuario ingresa datos incorrectos<br>**Cuando** intenta iniciar sesión<br>**Entonces** el sistema muestra un mensaje de error. | **EP07: User Management** |
